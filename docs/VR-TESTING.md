# 漓江回声 · VR 头显跑测指南(Quest 3)

本项目是 **MR 透视**节奏游戏,可靠的跑测方式是**把 APK 装进头显**在真机里玩。
编辑器里的 Link/串流一般**显示不出真实透视**,只适合调逻辑,不适合验收 MR 效果。

> 租来的头显(如淘宝租借)先看第 0 步:很多已经开好开发者模式,能省掉一整套账号设置。

---

## 0. 先别急着搞账号 —— 插电脑试一下能不能直接装

1. 装 **adb**(Android platform-tools),数据线连头显和电脑。
2. 终端跑 `adb devices`:
   - **列出设备且状态是 `device`** → 这台**已经开过开发者模式**,你什么账号都不用弄,直接跳到第 2 步出包(`Build And Run`)即可。
   - **列不出 / 显示 `unauthorized` / `no devices`** → 需要开开发者模式,进第 1 步。
   - `unauthorized` 时:头显里会弹"允许 USB 调试",勾"始终允许"再确认。

---

## 1. 开发者模式(只有第 0 步装不了才需要)

自建 APK(非商店)要头显处于**开发者模式**:

1. **手机装 Meta Horizon App**,配对这台头显。
   - 通常要用**你自己的 Meta 账号**登录才能改设置;租机可能锁在出租方账号上,**先问出租方能否配到你账号**(或它是否已开好开发者模式)。
2. 电脑浏览器上 developer.oculus.com **建一个免费开发者组织**(只需开启两步验证 2FA,**不用付款**)。
3. Horizon App → 设备 → **开发者模式 → 打开**。
4. 头显上同意 USB 调试;再回第 0 步 `adb devices` 确认能看到设备。

---

## 2. 从 Unity 出包装机

1. `File → Build Settings` 切到 **Android**。
2. 场景顺序按 `docs/WORKFLOW-BATTLE.md` 第 6 章「Build 时依次要选哪些场景」勾好。
3. 纹理压缩选 **ASTC**。
4. 头显用 USB 连着 → **`Build And Run`**,直接编译并安装进头显。
   - 或先 `Build` 出 `xxx.apk`,再命令行 `adb install -r xxx.apk`。
5. 戴上头显,在"未知来源 / 应用库"里找到本应用启动。

---

## 3. 常见问题

| 现象 | 处理 |
|---|---|
| `adb devices` 空 | 换根**能传数据**的线(有些线只供电);头显里确认已允许 USB 调试 |
| `unauthorized` | 头显里弹窗勾"始终允许"再确认;或 `adb kill-server && adb start-server` 重来 |
| 装上了但黑屏/没透视 | 确认是 Android **真机包**(不是编辑器 Link);确认权限里透视/相机已允许 |
| 租机改不了开发者模式 | 多半锁在出租方账号——联系出租方开开发者模式,或换一台已开好的 |
| 重装报签名冲突 | `adb uninstall <包名>` 后再装,或 `adb install -r` 覆盖安装 |

## 4. 快速迭代小抄

- 只调**玩法逻辑/数值**(不看透视):Unity 编辑器里用 `漓江回声/调试/进 战斗(关卡N)` 直接 Play 更快。
- 要**验收 MR 观感 / 手感 / 命中判定**:必须真机 APK。
- 改了 `.cs` 后:我这边推送 → 你 Unity `git pull` → 等编译 →(看逻辑就编辑器 Play / 看观感就 `Build And Run`)。
