# 漓江回声 · 做一个完整战斗关卡（端到端 workflow）

> 目标：从零把「战斗控制 + 谱面 + 纹样 + 手 + 场景」串起来，在 Battle_level1 上验证。
> 现状说明：战斗**逻辑**仍由主场景 `LijiangEchoMR_Main` 的运行时控制器跑；Battle_level1
> 通过「双模式采用」被战斗**当背景**用(可编辑、会动)。这是目前跑通完整战斗的方式
> (完全独立的 `BattleStageController` 是后续更大的一步,尚未做)。

## 完整步骤

### ① 音乐
1. 谱面编辑器 → 音频栏选你的音乐 → **准备音频** → **设为战斗音乐**(复制成 `battle_music`)。

### ② 谱面
2. 选**频段**(全频/低频鼓点/中频管乐)→ **检测拍子** →「用检测点重建」;或**目标拍子数**→均匀切/取最强N;或**检测→新图层**分乐器分层。
3. 改类型:逐个点改,或**批量面板**(整层全设 / 按比例分配 / 按类型替换删除 / 多选删除,支持 Ctrl+Z 撤销)。
4. 右下**「应用到」选关卡** → **保存到该场景**(写成 `chart_level0/1/2`,合并所有可见图层)。

### ③ 纹样(4 种打击各一个 Prefab)
5. 二选一:
   - 有美术:`生成4个可编辑纹样Prefab`(从现有 art)。
   - 从空搭:`生成4个空纹样Prefab`(中间占位圆点)→ 把你的 Sprite 拖到每个 `Visual`。
6. 双击 Prefab 调 `Visual` 的位置/大小;红点=对齐中心(仅编辑可见)。要白剪影:`纹样Prefab → 白剪影`。

### ④ 左右手
7. `生成左右手Prefab` → 双击 `Hand_Left/Right` 调 `Visual`(位置/大小/**Z 离镜头深度**)。

### ⑤ 战斗背景场景(Battle_level1)
8. 调试进战斗 Play → `场景化/1 A捕获` → 退出 Play → `1 B烘焙`(存成 `Battle_level1`)。
9. `场景化/2 让背景动起来` → Ctrl+S;若手臂脱开 `场景化/3 修手臂关节`。
10.(可选)`场景化/4 怪物做成共用Prefab` 让改动全关卡同步。

### ⑥ 接入战斗控制(让战斗用你的场景)
11. **File → Build Settings** 把 `Battle_level1` 拖进场景列表。
12. 跑 `LijiangEchoMR_Main` → `调试/进 战斗(关卡1)`。Console 出 `采用已烘焙背景「Battle_level1」…`。

### ⑦ 验证
13. 或直接在谱面编辑器 **「▶ 保存并试玩」/「从播放头试玩」** 一键进战斗,听音乐、看纹样飞入+手挥击、打点验证。
