# 漓江回声 · 战斗关卡制作指南(给组员)

> 这份文档面向**组内成员**,讲清楚目前(打磨后)战斗系统做到哪一步、以及**每个工具怎么用**。
> **重点是谱面编辑器(谱面生成器)**——它是你做一关最常用、功能最全的工具,单独用一大章讲。
>
> 一句话现状:战斗**逻辑**跑在主场景 `LijiangEchoMR_Main` 的运行时控制器上;`Battle_level1`
> 通过「双模式采用」被当作战斗**背景**(可编辑、会动)。这是目前跑通整关的方式(完全独立的
> BattleStageController 是后续)。所有工具都挂在 Unity 顶部菜单 **`漓江回声/…`** 下。

---

## 0. 五分钟看懂全流程

做一个完整战斗关卡 = **音乐 → 谱面 → 纹样 → 手 → 背景场景 → 接入 → 试玩**。

| 环节 | 用哪个工具 | 菜单 |
|---|---|---|
| ① 换/诊断战斗音乐 | 战斗音乐窗口 | `漓江回声/音频/战斗音乐(设置 + 诊断)` |
| ② **做谱面(核心)** | **谱面编辑器** | `漓江回声/谱面/0. 打开预览窗口` |
| ③ 四种打击纹样 | 纹样生成 + 绑定 | `漓江回声/纹样/…` |
| ④ 左右手 | 手 Prefab | `漓江回声/纹样/生成左右手Prefab` |
| ⑤ 战斗背景场景 | 场景化 1~4 | `漓江回声/场景化/…` |
| ⑥ 接入战斗 | Build Settings + 运行时 | Unity `File/Build Settings` |
| ⑦ 试玩验证 | 编辑器一键试玩 | 谱面编辑器里的「▶ 保存并试玩」 |

新人只做谱面的话,**只需要看第 1 章(战斗音乐)+ 第 2 章(谱面编辑器)** 就够了。

## 1. 先把战斗音乐设对(否则谱面没参照、试玩没声)

菜单 `漓江回声/音频/战斗音乐(设置 + 诊断)`:

1. 「选音频」拖入你的音乐 → **「设为战斗音乐」**。它会:自动删掉所有同名旧 `battle_music`
   文件(避免重名歧义)、复制到 `Resources/LijiangEchoAudio/battle_music`、并设成 **Decompress On Load**。
2. 点 **「诊断:运行时能读到吗?」** 确认输出是 `✅ 能读到 … 采样>0`。
3. ⚠️ **没声音先查两处**:
   - Game 视图右上角 **🔇 Mute Audio** 别点亮(点亮=静音,游戏就没声);
   - 运行时会自动补 `AudioListener`,看 Console 有没有 `战斗音乐开始…` 那行。
   - 注意:**编辑器里试听谱面的声音 和 游戏内音乐是两套**,编辑器能响不代表游戏能响,以上面诊断为准。

## 2. 谱面编辑器(谱面生成器)—— 核心工具,重点看这章

打开:`漓江回声/谱面/0. 打开预览窗口`。它像一个「音游版的视频剪辑器」:上面一条时间轴,
你在上面摆**打击点**、给每个点定**类型**、边听边对齐、然后保存成某一关的谱面。

### 2.1 四种打击类型(先记住,后面全靠它)

| 类型 | 中文 | 纹样 | 玩家动作(VR) |
|---|---|---|---|
| `single` | 单击 | 鱼纹 🐟 | 点一下(扳机/点击) |
| `double` | 双击 | 鸟纹 🐦 | 快速点两下 |
| `hold` | 长按 | 蛇纹 🐍 | 按住,沿线走完 |
| `swipe` | 挥划 | **蛙纹 🐸(青蛙纹)** | **快速挥动手柄扫过**(向内横扫,速度≥0.55m/s;或明显上下/前后挥) |

> 记法:**单点=鱼,双点=鸟,长按走线=蛇,挥手扫=蛙**。青蛙纹配「挥」——因为它就是要你甩手划过去。
> (早期需求把蛙纹画在了双击拍上;现在分成四类后,蛙纹归给 swipe,双击归给鸟纹。)

**挥划(swipe / 蛙纹)在 VR 里具体是什么动作?** —— 不是点扳机,是**挥动手柄(甩手)**,判定来自
手柄速度(`IsDeliberateBattleSwing`):

- 读左右手柄的移动速度,达到阈值(严格模式 **≥ 0.55 m/s**)才算;
- 方向要么**朝音符那一侧「向内横扫」**,要么有明显的**上下 / 前后挥**(纵向或纵深分量 ≥ 0.52 m/s);
- 命中后 0.25s 冷却、播 `swipe` 音效;**挥划完美给 150 分**(普通击打 120)。
- 无头显调试时的回退:**方向键** 或 **按住鼠标左键拖动**。

所以四类手感区分很清楚:**单击=点一下、双击=点两下、长按=按住沿蛇纹走、挥划=快速甩手扫过蛙纹**。

### 2.2 出拍子:三条路子(选一条起步)

顶部**音频栏**:选音频 →「准备音频」(想查接口点「诊断音频」)。然后:

- **A. 自动检测**:选**频段**(全频 / 低频=鼓点 / 中频=管乐)→「检测拍子」→「用检测点重建」。
  想按乐器分层,用「检测→新图层」把不同频段落到不同图层。
- **B. 定数量**:填「目标拍子数」→ **均匀切** 或 **取最强 N 个**。适合先铺个骨架。
- **C. 手摆**:什么都不检测,直接在时间轴上**空白处双击**加点。适合精修。

### 2.3 时间轴操作(像剪辑软件)

- **＋加音符 / 删除选中 / 撤销 / 重做**(工具栏按钮,快捷键 Ctrl+Z / Ctrl+Y);
- **拖动音符** = 改它的时间;
- **空白双击** = 在该处加一个音符;
- **Ctrl+点** = 多选;拖时间轴**顶部** = 移动播放头;
- 任何时候按下鼠标都会**先静音停止试听**,避免上一段音乐没停。

### 2.4 定类型 / 批量改(重点)

- **单个改**:选中一个音符,直接改它的类型。
- **批量面板**:
  - **整层全设**、**按比例分配**;
  - **自动撒挥划(旧规则)**——按老的取模规则撒 swipe,想快速铺一批蛙纹时用;
  - **按类型替换 / 删除**;
  - **全选类型 [单][双][长][划]** 四个按钮 + 删除选中(想「选中所有挥划」就点[划])。
- **重叠拍处理**:删其它层重叠拍 / 把重叠抽成新图层;**按类型拆成图层**(把四类各自拆开单独调)。

### 2.5 图层(Layers)

谱面是**多图层**的,每层有自己的颜色、可见开关。典型用法:低频鼓点一层、中频管乐一层、手摆特殊拍一层。
保存时会把所有**可见**图层合并。不想要某层就取消它的可见,或合并/删除。

### 2.6 边听边对齐(试听)

- 拖播放头**松手**就从那试听;
- **「只放拍子」** = 静音音乐、只按你的拍点响(对齐最稳,推荐);
- **「节拍声」** = 拍子叠在音乐上(可能被打断);
- **「响度」** 滑条控制拍子音量;不同类型音不同:单击一声、双击两声连击、长按/挥划各自的音。

### 2.7 谱面库 / 草稿(底部折叠区,别丢工作)

- 填个名字 **「另存为草稿」** → 把**全部图层**存成一份 JSON 草稿;
- 常驻列表显示每份的 **拍数 / 单双长划数量 / 应用于哪一关**;每行有 **载入 / 应用→0·1·2 / 删**;
- 覆盖关卡文件前会**自动备份**到 `Resources/LijiangEchoCharts/backup/`;
- 也可手动 `漓江回声/谱面/备份现有全部谱面`。

### 2.8 保存到关卡(出成品)

右下「应用到」选关卡(0/1/2)→ **「保存到该场景」**。它会:
- 写成 `chart_level{N}.txt`(带 `# types:explicit` 头 = **所见即所得**,运行时逐音符只认你写的类型);
- 合并所有**可见**图层;
- 状态栏显示**单 / 双 / 长 / 划**的数量,核对一眼再走。

### 2.9 一键试玩 + 联动(强烈推荐)

编辑器上的 **「▶ 保存并试玩」 / 「从播放头试玩」** 直接进战斗:
- **试玩联动**:进战斗后编辑器时间轴**自动跟随游戏进度**(只保留游戏声),游戏暂停即同步暂停;
  此时编辑器自己的 ▶/⏸ 会变成「跟随游戏进度中」并禁用。
- 玩法反馈:连击 ≥5 出黄色荡漾光环;音符到判定点按类型发声。

## 3. 纹样(四种打击各一个 Prefab)

菜单 `漓江回声/纹样/…`:

1. **生成 Prefab**:有美术就 `生成4个可编辑纹样Prefab`;从空搭就 `生成4个空纹样Prefab`(占位圆点),
   再把 Sprite 拖到每个 `Visual`。
2. **调整**:双击 Prefab 改 `Visual` 的位置/大小;根上**红点=对齐中心**(仅编辑器可见,Play 不显示)。
   要白剪影风格:`纹样Prefab → 白剪影`。
3. **按关卡/全局换某类型纹样**:`漓江回声/纹样/纹样绑定` → 选贴图 + 绑定到(全局 / 关卡0·1·2)+ 打击类型 → 生成并绑定(自动居中+统一大小)。「待描绘纹样」也在这换。
   - 运行时优先级:`Note_level{关卡}_{类型}` → 全局 `Note_鱼/鸟/蛇/蛙` → 代码回退。

---

## 4. 左右手

`漓江回声/纹样/生成左右手Prefab` → 双击 `Hand_Left/Right` 调 `Visual`(位置/大小/**Z 离镜头深度**);
根红点=旋转轴心(肩)。运行时只驱动旋转 + 淡入。

---

## 5. 战斗背景场景(Battle_level1)

`漓江回声/场景化/…`:

1. 调试进战斗 Play → `1 A捕获` → 退出 Play → `1 B烘焙`(存成 `Battle_level1`);
2. `2 让背景动起来` → Ctrl+S;手臂脱开用 `3 修手臂关节`;(可选)`4 怪物做成共用Prefab` 全关卡同步。

---

## 6. 接入战斗

1. **File → Build Settings** 把 `Battle_level1` 拖进场景列表;
2. 跑 `LijiangEchoMR_Main` → `漓江回声/调试/进 战斗(关卡1)`;Console 出 `采用已烘焙背景「Battle_level1」…` 即成功。

---

## 运行时约定(已生效,无需手动操作)

- **按关卡选谱**:优先 `chart_level{关卡}` → `chart_generated` → `chart_liusanjie`(默认/兜底)。
- **默认谱 `chart_liusanjie`** 已带四类拍子:单击(鱼)/ 双击(鸟)/ 长按(蛇)/ 挥划(蛙)俱全。
- **显式类型**:编辑器保存的谱带 `# types:explicit` 头 → 运行时**逐音符只认写的类型**,不再取模自动撒挥划。
- **战斗背景双模式**:进战斗若已加载 `Battle_level1`(在 Build Settings)就自动采用+驱动动效;否则运行时构建。
- **纹样/手 Prefab 优先**:`Resources/LijiangEchoNotes/` 下有就用你的 Prefab。
- **音符按类型发声** + **连击 ≥5 黄色光环**。
