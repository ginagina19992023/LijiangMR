# 漓江回声 · 做一个完整战斗关卡（端到端 workflow）

> 目标：从零把「战斗控制 + 谱面 + 纹样 + 手 + 场景」串起来，在 Battle_level1 上验证。
> 现状：战斗**逻辑**仍由主场景 `LijiangEchoMR_Main` 的运行时控制器跑；Battle_level1 通过「双模式采用」
> 被战斗**当背景**用(可编辑、会动)。这是目前跑通完整战斗的方式(独立 BattleStageController 是后续)。

---

## 工具齐全性 ✅
| 环节 | 用的工具 |
|---|---|
| 谱面(音乐→拍子→类型→图层→草稿库→保存) | 谱面编辑器 `谱面/0. 打开预览窗口` |
| 换/诊断战斗音乐 | `音频/战斗音乐（设置 + 诊断）` 或编辑器音频栏 |
| 纹样(4 种打击) | `纹样/生成4个可编辑纹样Prefab` 或 `生成4个空纹样Prefab` |

| 左右手 | `纹样/生成左右手Prefab` |
| 战斗背景可编辑/动/修手臂/怪物Prefab | `场景化/1~4` |
| 战斗用该场景 | Build Settings 加场景 + 运行时双模式采用 |
| 试玩验证 | 编辑器「▶ 保存并试玩 / 从播放头试玩」 |

## 完整步骤

### ① 音乐
1. `音频/战斗音乐（设置 + 诊断）` → 选你的音乐 → **设为战斗音乐**(自动删同名旧文件+设 Decompress)→ **诊断** 确认"能读到、采样>0"。
2. ⚠️ **没声音先查两处**:Game 视图右上角 **🔇 Mute Audio** 别点亮;运行时会自动补 AudioListener(看 Console `战斗音乐开始…` 那行)。

### ② 谱面(编辑器 `谱面/0. 打开预览窗口`)
3. **音频栏**:选音频 →「准备音频」;点「诊断音频」可查接口。
4. **出拍子**:选**频段**(全频/低频鼓点/中频管乐)→「检测拍子」→「用检测点重建」;或**目标拍子数**→均匀切/取最强N;或**检测→新图层**分乐器成层。
5. **时间轴工具栏(像视频编辑器)**:＋加音符 / 删除选中 / 撤销 / 重做;**拖动音符=改时间**、**空白双击=加音符**、Ctrl点=多选、拖顶部=移动播放头。
6. **改类型**:单个点改;或**批量面板**——整层全设、按比例分配、**自动撒挥划(旧规则)**、按类型替换/删除;**全选类型[单][双][长][划]** + 删除选中。**重叠拍**:删其它层重叠拍 / 抽成新图层;**按类型拆成图层**。
7. **试听对齐**:拖播放头松手试听;**「只放拍子」**=静音音乐只按拍点响(最稳);「节拍声」叠在音乐上(可能被打断);「响度」滑条控制拍子音量(单击一声、双击两声连击、长按/挥划不同音)。
8. **谱面库/草稿(底部折叠区)**:填名字「另存为草稿」存**全部图层**;常驻列表显示每份的 拍数/单双长划/应用于哪关;每行 **载入 / 应用→0·1·2 / 删**。覆盖关卡前自动备份到 `backup/`;菜单 `谱面/备份现有全部谱面`。
9. **应用到关卡**:右下「应用到」选关卡 →「保存到该场景」(写成 `chart_levelN`,合并所有**可见**图层;状态栏显示 单/双/长/划 数量)。

### ③ 纹样(4 种打击各一个 Prefab)
10. 二选一:有美术 `生成4个可编辑纹样Prefab`;从空搭 `生成4个空纹样Prefab`(占位圆点)→ 把 Sprite 拖到每个 `Visual`。
11. 双击 Prefab 调 `Visual` 位置/大小;根上红点=对齐中心(仅编辑可见,Play 不显示)。要白剪影:`纹样Prefab → 白剪影`。
12. **换某关卡/全局的某类型纹样**:`纹样/纹样绑定` 窗口 → 选贴图 + 绑定到(全局/关卡0·1·2)+ 打击类型 → 生成并绑定(自动居中+统一大小)。「待描绘纹样(右下角)」也在这里换。
    - 运行时优先级:`Note_level{关卡}_{类型}` → 全局 `Note_鱼/鸟/蛇/蛙` → 代码回退。

### ④ 左右手
13. `生成左右手Prefab` → 双击 `Hand_Left/Right` 调 `Visual`(位置/大小/**Z 离镜头深度**);根红点=旋转轴心(肩)。运行时只驱动旋转+淡入。

### ⑤ 战斗背景场景(Battle_level1)
14. 调试进战斗 Play → `场景化/1 A捕获` → 退出 Play → `1 B烘焙`(存成 `Battle_level1`)。
15. `场景化/2 让背景动起来` → Ctrl+S;手臂脱开 `场景化/3 修手臂关节`;(可选)`场景化/4 怪物做成共用Prefab` 全关卡同步。

### ⑥ 接入战斗控制
16. **File → Build Settings** 把 `Battle_level1` 拖进场景列表。
17. 跑 `LijiangEchoMR_Main` → `调试/进 战斗(关卡1)`。Console 出 `采用已烘焙背景「Battle_level1」…`。

### ⑦ 验证(推荐)
18. 谱面编辑器 **「▶ 保存并试玩」/「从播放头试玩」** 一键进战斗。
    - **试玩联动**:进战斗后编辑器时间轴**自动跟随游戏进度**(只保留游戏声),游戏暂停即同步暂停,编辑器 ▶/⏸ 变「跟随游戏进度中」。
    - 玩法反馈:连击≥5 会有黄色荡漾光环;音符到判定点按类型发声。

## 运行时约定(已生效,无需操作)
- **按关卡选谱**:优先 `chart_level{关卡}` → `chart_generated` → `chart_liusanjie`。
- **战斗背景双模式**:进战斗若已加载 `Battle_level1`(在 Build Settings)自动采用+驱动动效;否则运行时构建。
- **纹样/手 Prefab 优先**:`Resources/LijiangEchoNotes/` 下有就用你的 Prefab。
- **音符按类型发声** + **连击≥5 黄色光环**。
