## A. 谱面编辑器（漓江回声/谱面/0. 打开预览窗口）

一站式：选音乐 → 出拍子 → 改类型 → 分图层 → 保存到关卡 → 试玩。

### 1) 音频栏（顶部）
- **对象框**：选项目里任意音频（mp3/wav/ogg 都行）；波形/检测/试听都用所选这首。
- **准备音频**：一键设 Decompress On Load（并给当前平台建 Override，修"改 Default 又跳回 Streaming"）。压缩/mp3 必须先准备才能读采样。
- **设为战斗音乐**：复制成 `Resources/LijiangEchoAudio/battle_music`，让运行时用这首。

> 若"准备"后仍读不了：在音频 Inspector 顶部平台标签页（PC/Standalone）勾 Override + Load Type=Decompress On Load + Apply；实在不行把音乐转成 WAV 再导入。

### 2) 出拍子（检测行）
- **灵敏度 / 最小间隔**：越大越稀疏（最小间隔可到 1 秒）。
- **频段**：`全频 / 低频·鼓点(20-150Hz) / 中频·管乐(300-2000Hz)`——只扒某类乐器。
- **检测拍子**：出浅色参考点（会自动准备音频）。
- **用检测点重建**：把参考点变成音符（全单击）。
- **目标拍子数** + **均匀切N个**（按时长等分）/ **取最强N个拍子**（跟音乐，保留最强 N）。

### 3) 图层（时间轴上方）——分离/合并不同乐器的拍
- 每层：选中编辑(圆点)、改色、改名、显示开关、拍数、删除。
- **检测→新图层**：用当前频段检测，结果放进**新层**（不动其它层）。例：选「低频·鼓点」→ 鼓点层；选「中频·管乐」→ 管乐层。
- **合并可见图层→新层**：把可见层拍点合成一层。
- **从文件导入→新图层**：读 `time,type` 文件（就是下面 Python 脚本的输出）成一层。
- 时间轴把其它可见图层画成底色细线；当前层在上可点选改类型。

### 4) 编辑 / 试听
- 拖**红色播放头**松手即试听那段；点音符竖线选中 → 改类型(单击/双击/长按/挥划)、增删、对齐检测点。

### 5) 保存 / 试玩（右下）
- **应用到**：选关卡(蛙0/鸟1/鱼2 / 全局)。
- **💾 保存到该场景**：把**所有"可见"图层**合并（20ms 去重）写成该关卡谱面 `chart_levelN`（带 types:explicit，运行时所见即所得）。想排除某层就把它隐藏。
- **▶ 保存并试玩**：保存后直接进 Play 战斗，听音乐/看纹样/打点验证；停止 Play 回编辑。

## B. 离线扒谱脚本（tools/lijiang_beatmap.py）——最干净的鼓点

用 librosa HPSS 把打击成分单独抽出来做检测，比编辑器内的检测更干净。
```
pip install librosa numpy soundfile

# 扒鼓点 → 直接存成关卡1谱面
python lijiang_beatmap.py song.mp3 --mode drums --out ../Assets/Resources/LijiangEchoCharts/chart_level0.txt

# 一次导出 鼓点/谐波/全频 三个文件（当不同图层导入）
python lijiang_beatmap.py song.mp3 --emit-layers --out-dir layers/
```
- `--mode full/drums/harmonic/low/mid`、`--top N`(取最强)、`--min-gap`、`--type single/double/hold/swipe`。
- 输出的文件用编辑器「从文件导入→新图层」导入 → 可切换/隐藏/合并/保存。

## C. 纹样 Prefab（鱼/鸟/蛇/蛙）——你自己拖着改

运行时读不了压缩贴图像素，所以纹样改成 Prefab，视觉全由你在编辑器决定。

- **生成**：`漓江回声/纹样/生成4个可编辑纹样Prefab` → `Resources/LijiangEchoNotes/Note_{Fish,Bird,Snake,Frog}.prefab`（用 GPU blit 读像素、自动居中，兼容 Crunch 贴图）。
- **编辑**：双击某个 Prefab → 拖里面的 **`Visual`** 改位置/大小、换 Sprite；编辑/删 **`Glow`** 调光晕。根上有 **中心对齐点**(红色十字，只在 Scene 视图显示、游戏里不显示)方便对齐。
- **变白/彩色**：`纹样Prefab → 白剪影` / `→ 原彩色`（一键切 4 个的本体材质，白剪影用 LijiangEcho/WhiteSilhouette）。
- 运行时优先用这些 Prefab；删掉某个 → 该纹样回退旧代码生成。

## D. 场景化 / 布局 / 怪物 Prefab

- **烘焙关卡**：调试进战斗 Play → `通用A 捕获` → 退出 Play → `通用B 烘焙` → 存成关卡场景（如 `Battle_level1`）。
- **让背景动**：打开关卡场景 → `为战斗背景补挂动效组件` → Ctrl+S。
- **修手臂关节脱开**：打开关卡 → `布局同步/③ 修复怪物手臂关节` → Ctrl+S。
- **关卡间同步布局**：改好一关 → `布局同步/① 采集` → 别的关 `② 应用`。
- **怪物即 Prefab(改一次全关卡同步)**：参考关调好 → `怪物Prefab/① 存为怪物Prefab`；别的关 `② 用Prefab替换`。以后改 `Assets/Prefabs/BattleMonster.prefab` 全关卡同步。

---

## E. 运行时约定（代码里已生效，无需操作）

- **按关卡选谱**：优先读 `chart_level{关卡}` → `chart_generated` → `chart_liusanjie`。
- **战斗背景双模式**：进战斗若已加载名为 `Battle_level1` 的烘焙场景（需加入 Build Settings），自动采用它+驱动动效；否则运行时构建。
- **纹样 Prefab 优先**：`Resources/LijiangEchoNotes/Note_*` 存在就用你的 Prefab。
- **音符按类型发声**：到判定点自动响（便于听着谱面调试）——单击=hit×1、双击=hit×2、长按=snake、挥划=swipe。
