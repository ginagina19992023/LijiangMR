《漓江回声MR》VR版本修改需求

项目名称：漓江回声MR
文档用途：明确当前VR版本的修改内容及验收要求

一、整体流程

开始界面 → 关卡选择 → 摇杆前进与三段图案绘制 → 过渡视频 → 打击关卡 → 成功／失败结果 → 卡面解析与切换


二、具体修改需求

1. 开始界面位置调整

修改要求：
当前开始界面在VR设备中的显示位置偏低，玩家需要低头才能看见。请将界面调整至玩家正常平视时的视觉中心区域。

验收要求：
进入程序后，玩家保持自然平视即可完整看清并操作开始界面，无需明显低头。


2. 关卡选择界面调整

修改要求：
当前版本只需要开放一个关卡，即蛙纹关卡。其余两个关卡图案保持变暗并禁止进入，作为后续新增关卡的预留位置，暂时不需要制作成可游玩关卡。

验收要求：
蛙纹关卡可以正常点击进入；另外两个关卡显示为未开放状态，无法点击进入。



3. 第二章节加入三段图案绘制

修改要求：
将完整前进过程划分为三段，每完成一段前进后进入一次图案绘制，共完成三次绘制，再继续后续流程。绘制内容不能集中放在前进结束后一次性完成。加入补充的箭头，字幕等美术素材

建议流程：
第一段前进 → 第一次绘制 → 第二段前进 → 第二次绘制 → 第三段前进 → 第三次绘制 → 播放过渡视频 → 进入打击关卡。

验收要求：
三次绘制分别穿插在三段前进过程中，触发顺序正确，完成当前绘制后才能继续下一段。

参考视频：点击图标出现的提示demo


4. 图案绘制位置与尺寸调整

修改要求：
当前VR中的图案与绘制路线没有正确对齐，并且图案整体尺寸过小。请统一调整图案和绘制路线的位置、角度及比例，同时适当放大图案，保证玩家容易看清并完成绘制。

验收要求：
图案与路线准确重合；图案尺寸适合VR观看和手柄操作；绘制时不会出现明显错位。


5. 绘制完成后的过渡视频调整

修改要求：
完成第三次图案绘制后播放指定的过渡视频。视频播放到需要的结束位置后，直接切换至打击界面，不需要继续播放多余片段。

验收要求：
第三次绘制完成后自动播放视频；视频在指定位置结束；结束后能够顺利进入打击关卡，不出现卡顿、黑屏或重复播放。

参考视频：动画视频.mp4


6. 暂停界面调整

修改要求：
当前暂停界面的图标过小并且错位，并且在VR设备中点击后无法正常执行功能。请放大图标和可交互区域，并修复按钮的点击与功能响应。

验收要求：
暂停界面的图标清晰可见；使用VR控制器可以稳定点击；所有按钮均能执行对应功能。



7. 打击界面判定规则调整

修改要求：
从左侧出现的音符只能使用左手控制器打击，从右侧出现的音符只能使用右手控制器打击。双手音符必须由左右手同时完成打击才能触发成功。当前任意一只手均可打击所有音符且忽略方向的判定方式需要修改。

验收要求：
左侧音符只响应左手；右侧音符只响应右手；使用错误的手打击时判定失败；双手音符只有在左右手同时满足判定条件时才算成功。




8. 打击结果与卡面解析调整

修改要求：
打击关卡结束后，先显示“成功”或“失败”的结果标识，再进入卡面解析界面。现有美术素材中的全部卡面都需要加入程序，不能只显示一张，并且需要提供卡面切换功能。

验收要求：
关卡结束后能够正确显示成功或失败结果；随后进入卡面解析；全部卡面素材均已加入；玩家可以正常切换和查看不同卡面。

三、开发前需要确认的内容

1. 三段前进过程各自的触发位置和长度。
2. 三次图案绘制分别使用的图案素材及顺序。
3. 过渡视频需要保留的准确起止时间。
4. 暂停界面各按钮需要实现的具体功能。
5. 双手音符允许的同时打击时间误差范围。
6. 卡面素材的总数量、展示顺序及切换方式。


四、最终验收流程

开始界面位置正确 → 进入唯一开放关卡 → 完成三段前进和三次绘制 → 播放过渡视频 → 进入打击关卡 → 左右手及双手判定正确 → 显示成功／失败结果 → 进入卡面解析并能够切换全部卡面。
